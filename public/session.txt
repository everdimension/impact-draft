│ Plan to implement                                                            │
│                                                                              │
│ Plan: Add diverging bar chart above engineer cards                           │
│                                                                              │
│ Context                                                                      │
│                                                                              │
│ The engineer list is sorted by composite impact score, but there's no visual │
│  overview of how engineers compare on their quality ratio. You have to       │
│ expand each card to see if someone's ratio is 6.0 or 0.35. A chart above the │
│  list gives that signal at a glance and makes positive vs negative impact    │
│ immediately visible.                                                         │
│                                                                              │
│ Design: Diverging horizontal bar chart (inline SVG, no library)              │
│                                                                              │
│               0              1.0              6.0                            │
│               ├──── below ────┼──── above ────┤                              │
│ alice (12)                    │████████████████  6.0                         │
│ bob (8)        ██████████████│                  0.35                         │
│ carol (3)      ███████████████│                  0.18                        │
│ dave (1)                      │-                 --                          │
│                                                                              │
│ - Center line at 1.0 — the quality threshold. This is the visual anchor.     │
│ - Right bars (green #16a34a) — ratio > 1.0, positive impact                  │
│ - Left bars (amber #b45309) — ratio < 1.0, negative impact                   │
│ - Null ratios — gray dash at center, -- as value                             │
│ - Row labels — engineer name + PR count in parens, monospace                 │
│ - Value labels — ratio to 1 decimal on the right side                        │
│ - Axis header — "0" at left edge, bold "1.0" at center, max value at right   │
│ edge                                                                         │
│                                                                              │
│ Scale                                                                        │
│                                                                              │
│ Left half (0 → 1.0) and right half (1.0 → max) each get 50% of bar width.    │
│ This keeps 1.0 always centered so the divergence is visually clear. Bars     │
│ grow outward from the center line.                                           │
│                                                                              │
│ Responsiveness                                                               │
│                                                                              │
│ - SVG uses viewBox="0 0 800 {height}" with width: 100%; height: auto —       │
│ scales proportionally                                                        │
│ - Mobile (< 640px): hide chart entirely (matches existing pattern)           │
│                                                                              │
│ Height budget (10 engineers, 768px viewport)                                 │
│                                                                              │
│ - Row height: 24px (16px bar + 8px gap)                                      │
│ - SVG: ~28 header + 10×24 rows + 8 padding = 276 viewBox units               │
│ - Rendered at 728px container width: ~251px                                  │
│ - Remaining for cards: 768 − 80 (header) − 70 (results) − 251 (chart) − 40   │
│ (padding) = 327px → ~5 cards visible ✓                                       │

│ Steps                                                                        │

│ 1. Create src/components/ImpactChart.tsx                                     │
│                                                                              │
│ Pure functional component, no state/effects. Accepts { reports:              │
│ EngineerReport[] }.                                                          │
│                                                                              │
│ Layout constants (viewBox coordinates):                                      │
│ - LEFT_LABEL = 0..140 — engineer name (text-anchor: end at x=136)            │
│ - BAR_AREA = 140..660 — 520 wide, center at x=400                            │
│ - RIGHT_LABEL = 660..800 — ratio value (text-anchor: start at x=664)         │
│ - HEADER_H = 28, ROW_H = 24, FOOTER_H = 8                                    │
│                                                                              │
│ Scale function:                                                              │
│ function ratioToX(ratio: number, maxRatio: number): number {                 │
│   if (ratio <= 1) return BAR_LEFT + (ratio / 1) * HALF_WIDTH;                │
│   return CENTER_X + ((ratio - 1) / (maxRatio - 1)) * HALF_WIDTH;             │
│ }                                                                            │
│                                                                              │
│ SVG structure:                                                               │
│ 1. Background rect on bar area (var(--code-bg))                              │
│ 2. Dashed center line at x=400                                               │
│ 3. Axis labels: "0", "1.0" (bold), max value                                 │
│ 4. Per-engineer rows: name label, colored bar (or gray dash for null), value │
│  label                                                                       │

│                                                                              │
│ Edge cases:                                                                  │
│ - All null → show dashes, maxRatio defaults to 2.0                           │
│ - Ratio exactly 1.0 → minimum bar width of 2 units, green                    │
│ - Very long names → truncate at 14 chars                                     │
